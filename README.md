# Guideline and delivery gaps in undiagnosed diabetes, prediabetes, and hypertension (NHANES 2017-2023)

Target journal: JAMA Network Open (Original Investigation).

| Path | What it holds |
|---|---|
| `manuscript/Manuscript_JAMANetwOpen_UndiagnosedDiabetesHypertension.docx` | Full manuscript: title page, Key Points, abstract, text, 37 references, Tables 1-2, Figures 1-3, Supplement 1 (eMethods, eTables 1-6, eFigure 1) |
| `manuscript/manuscript_src.Rmd` | Manuscript source; every number is pulled live from the R outputs |
| `manuscript/build.R` | Numbers citations, inserts AMA references, renders Word |
| `brief/Policy_Brief_Undiagnosed_Diabetes_Hypertension.pdf` | One-page policy brief (Typst source `brief/brief.typ`, built by `R/06_brief.R`) |
| `R/00_download.R` | Downloads the NHANES 2017-Mar 2020 and Aug 2021-Aug 2023 files from the CDC |
| `R/01_data.R` | Merges and harmonizes NHANES 2017-Mar 2020 and Aug 2021-Aug 2023 |
| `R/02_analysis.R` | Survey-weighted prevalence, counts, criteria gaps, delivery gaps, sensitivity analyses |
| `R/03_ml_conformal.R` | Risk models (logistic splines, XGBoost), weighted Mondrian split-conformal rules, temporal validation |
| `R/04_figures.R` | Figures 1-3 and the participant flow diagram (PNG and TIFF, 600 dpi) |
| `R/05_tables.R` | Formatted tables |
| `figures/` | Submission-ready figure files |
| `output/` | Saved estimates (.rds and .csv) |

## Reproduce

Requires R (4.4 or later) with `haven`, `dplyr`, `tidyr`, `purrr`, `survey`, `xgboost`, `ggplot2`, `patchwork`, `ragg`, `flextable`, `officer`, `rmarkdown`, and Quarto (for the brief).

```bash
Rscript run_all.R
```

`R/00_download.R` fetches the public NHANES files from the CDC into `data/raw/`; every later step reads from there. Data, results, figures, and rendered documents are not tracked in git; they are regenerated by the pipeline.
